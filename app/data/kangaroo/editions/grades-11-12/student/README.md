# Grades 11–12 (Student) source catalog

This metadata-only catalog records the Student paper and shared answer-PDF links listed by the [Matematica.pt past-paper index](https://www.matematica.pt/en/useful/kangaroo-questions.php). The index is a discovery source; the linked PDFs should be checked directly before preparing any edition content. The answer PDFs may contain multiple groups, so use only the section matching the Student paper and year.
